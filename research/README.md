## How to read these

Each report separates what was verified from what was not. Where a researcher
could not reach a primary source it says so rather than guessing, and those
flags were preserved deliberately.

Claims re-verified first-hand afterwards are marked in the strategy document.
The rest is desk research with the confidence its sources support — useful for
direction, not for a slide.

## One correction worth carrying forward

The first version of this research answered the wrong question. It assumed we
were an independent vendor choosing a market, and concluded that e-invoicing for
Shopify and Shopware was the opportunity.

The actual question is which third-party systems should connect **into**
Scopevisio, toward a connector marketplace — and Scopevisio already sends
e-invoices. Report 03 is kept for reference but is not a roadmap item, and
report 04's conclusion (don't) stands on its own terms.
